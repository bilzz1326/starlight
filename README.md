# Starlight

A one-tap space adventure for kids. Help **Lumi**, a little spark of sunlight, wake up the sleepy planets on a journey from the Sun to the Andromeda Galaxy. Every world Lumi reaches lights up and shares a real fun fact.

## Play

Open `index.html` in any modern browser. No install or build step is needed.

- **Tap / click / Space:** launch Lumi toward the next world
- **P or Esc:** pause

## Features

- 35 real objects in order outward, from the Sun and planets to nearby stars, nebulae, a black hole and galaxies, then endless deep space
- A kid-friendly fun fact for every object, with a **Listen** button that reads it aloud
- A picture quiz that relights Lumi when the light runs out
- Five chapters with checkpoints, plus a new twist in each: shooting comets, space rocks and black holes that pull Lumi in
- Explorer mode (relaxed, with a guide line) and Challenge mode
- Daily missions, a day streak, stardust and outfits for Lumi
- A Logbook of everything discovered
- Music and sound generated in code, so there are no audio files to license

## Files

| File | What it holds |
|---|---|
| `index.html` | The game: layout, styles and code |
| `data.js` | All space content: names, colors, fun facts and quiz questions. Edit this to change or add facts. |
| `voice-script.txt` | Lines and file names for recording the narrator voice |
| `voice/` (optional) | Recorded MP3s. When a file is missing, the game uses the device's built-in voice. |

Keep `index.html` and `data.js` in the same folder.

## Saved progress

Best scores, the Logbook, stardust and outfits are saved in the player's browser. The online leaderboard currently works only when the game is opened from its claude.ai link. A public leaderboard is planned.

## Privacy

The game asks for no personal information. Players appear on the leaderboard only under a randomly generated nickname, such as "Happy Otter 37".
