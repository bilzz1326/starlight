STARLIGHT - NARRATION SCRIPT FOR RECORDED VOICE
================================================

How to use:
1. In ElevenLabs (or a similar voice tool), pick one warm, friendly voice and use it for every line.
2. Generate each line below and download it as an MP3.
3. Save each file with the exact file name shown, inside a folder called "voice"
   next to index.html:   D:\my Docs\starlight\voice\the-sun.mp3   (and so on)
4. The game plays the recording when a player taps "Listen". If a file is missing,
   it falls back to the device's built-in voice, so you can add files a few at a time.

Tip: speak slowly and warmly, like reading to a 6-year-old. Leave a short pause after the name.
